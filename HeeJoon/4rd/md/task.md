# 한국 약품 → 해외 약품 매칭 시스템 개선 방안

## 목표
한국 약품명 입력 → 성분 추출 → 해외(미국 FDA) 동일 성분 약품 안내

## 작업 항목

### 분석 및 설계
- [x] 현재 프로젝트 구조 분석
- [x] 장단점 파악
- [x] 한국-미국 의약품 분류 체계 차이 조사
- [x] 복합제 처리 방안 설계
- [x] OpenFDA API 복합 검색 방법 확인

### 핵심 발견사항
- ✅ 한국과 미국의 OTC/처방전 분류 기준이 **다름** (특히 용량 차이)
- ✅ OpenFDA API는 `+AND+` 연산자로 복합 성분 검색 가능
- ✅ 동일 성분도 용량에 따라 분류가 달라질 수 있음
- ✅ 복합제는 정확히 일치하지 않을 수 있으므로 "유사도" 개념 필요

### 구현 방향성
- [ ] 한국 약품 데이터 통합 (식약처 API 또는 로컬 DB)
- [ ] 복합제 검색 로직 구현 (AND 검색 → 실패 시 주성분)
- [ ] 분류 차이 경고 시스템
- [ ] 프롬프트 최적화 (복합제용 템플릿)
- [ ] UI 개선 (유사도 표시, 차이점 강조)
